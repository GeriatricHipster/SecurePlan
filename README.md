- added Panic Button and Lock Down Button to Access Control

- included a simple App.jsx routing example

## Files included

## Important

This is a change bundle, not a full cloned repo. Copy these files into the matching paths in your SecurePlan project, then merge the logic into your existing components where needed.

If your app already has these files, compare and replace only the matching sections.
